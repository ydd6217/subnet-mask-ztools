# 子网掩码计算器（ZTools 插件）

ZTools 插件：输入 IP + 子网掩码（点分十进制或 `/CIDR`），即时得到网络地址、广播地址、可用主机范围与数量。全部本地计算，零网络请求。

## 功能

| 标签页 | 指令 | 说明 |
| --- | --- | --- |
| 子网计算 | `子网掩码` / `子网计算` / `subnet`，或直接粘贴 `192.168.1.100/24` | 网络地址、广播地址、可用主机范围、主机数、子网大小、主机位、掩码点分/CIDR/十六进制 |
| 网络与 IP 计算器 | `子网划分` / `网络计算器` / `IP地址计算器` | 输入 IP + 网络类型（默认自动判定或强制 A/B/C 类）+ 子网数量（或直接给掩码），得到网络类别、自然掩码、子网掩码、反掩码、借位数、网段数量、每段主机数、输入 IP 所在网段，以及网络列表表格（序号/网络/起始/结束/广播地址，所在行高亮）。子网数量按 2 的幂向上取整 |
| 掩码互转 | `掩码互转` / `子网掩码转换` | 点分十进制 ↔ `/n` ↔ 十六进制 |
| 主机数反推 | `反推掩码` / `主机数反推` | 按需要的可用主机数向上取 2 的幂，给出最小 CIDR 与掩码 |

`/31` 按 RFC 3021 视为点对点链路（2 个可用地址），`/32` 为单主机地址。D 类多播、E 类保留、127 回环与 0 段地址会直接报错并说明原因；掩码短于自然掩码时按超网汇总列出被覆盖的自然网段。

网络列表一次最多渲染 60 行（`PLAN_ROW_LIMIT`），窗口自动居中到输入 IP 所在网段，其余行数在表头注明——A 类划到 /27 是 52 万个子网，不做窗口会卡死。

粘贴 IP 时命中正则指令，会自动预填并切到对应标签页（单独一个掩码如 `255.255.255.128` 或 `/24` 会进「掩码互转」）。

## 目录结构

`plugin.json` 与 `logo.png` 只在项目根目录维护一份，`npm run build` 后由 `scripts/postbuild.mjs` 复制进 `dist/`。

## 开发与构建

```bash
npm install
npm run build   # 产出 dist/：index.html + assets/ + plugin.json + logo.png
npm run pack    # 再把 dist 打包为 subnet-mask-1.1.0.zpx（ZTools 本地导入用）
npm run dev     # http://localhost:5180，仅在支持开发项目的界面上使用
```

## 安装到 ZTools 3.2.0

ZTools 的「导入本地插件」文件选择框只接受 `.zpx` 与 `.zip`，所以要先 `npm run pack`：

1. ZTools → 设置 → 插件管理 → 点「导入本地插件」；
2. 选择 `/yzz/qoder/subnet-mask/subnet-mask-1.1.0.zpx`，在预览页确认安装。

安装后插件实体会落成 `~/.ztools/plugins/subnet-mask-1.0.0-<hash>.asar`，注册记录写入 `~/.ztools/lmdb` 的 `ZTOOLS/plugins`。

唤起方式：搜索「子网掩码」，或直接粘贴 `192.168.1.100/24`。

改代码后要重新 `npm run pack` 并再导入一次覆盖安装。
